# 下一 Agent 执行指令：FACAI 站点体检发布闭环

最终产品目标：站点负责人提交 URL 后，以尽可能短的响应时间覆盖其网站适用的
技术栈与已知漏洞类别，经过证据去重、验证和人工可复核分级，交付准确、可追溯、
可领取的风险报告。当前只完成入口基础，不得将局部已实现能力误写成最终范围；
也不得宣称无法证实的项目已检出或所有漏洞已覆盖。

先核对 GitHub `lwt131619/facai-latest-source-chatgpt` 的 `main`，阅读仓库根目录
`AGENTS.md`、`FACAI_CODEX_HANDOFF.md`、`AGENT_HANDOFF.md`，以及
`docs/engineering/REQUIREMENTS_TRACEABILITY.md`。代码与实测为准，不用旧 ZIP
覆盖。每个可运行断点更新交接和任务登记、测试、经 `scripts/checkpoint.py` 提交推送，
核对 `remote_verified` 和 `main` SHA。

## 产品边界与最快交付顺序

用户提交自己管理的域名 → 会话认领 → HTTPS 验证文件证明控制权 → 只读检查 →
逐条证据与修复建议 → 报告领取 → Owner 确认。原始目标、权限判定、执行、验证分开。
未知保持 UNKNOWN，不以版本号或缺失响应头推断 PHP 漏洞已证实。

1. **双域名部署**：先查 VPS 当前 SHA、端口、证书、Nginx 站点和备份。
   `deploy/deploy.sh` 虽接受 `FACAI_DOMAIN`，其 Nginx 模板仍写死 `whstapp.lol`；
   不可直接以新域名运行 `update/install/cert` 来覆盖旧站。实现独立的
   `opencodemarketing.top` + `www` vhost 和证书，使两个域名指向同一
   `127.0.0.1:8765` 服务；保留旧域名、SSE、限流、CSP、HSTS 与 ACME 路径。
   仓库有 `deploy/add-marketing-domain.sh` 作为独立安装入口，运行前核对其
   环境和模板，不能跳过备份及 DNS 门。
   验证权威 DNS 指向实际 VPS IP 后才签证书。部署前后核对旧域名仍可用。
2. **闭环 UI**：`/site-assessment` 已能认领、验证、运行、读取单站点报告。
   做真实浏览器及手机走查；补访问历史列表、明确等待/失败/重试状态、报告导出。
3. **证据与 Proof**：将实际观察的响应元数据、采集时间、规则版本、来源和哈希
   接入现有 Trust/Artifact/Trace。只有站点控制权验证后的 Owner 可领取完整报告；
   跨 Owner 返回 404。失效验证文件时停止后续采集。
4. **覆盖范围**：产品面向多技术栈。先扩充少量可解释、低负载的公开配置检查；
   源码或 SBOM 由站点负责人上传时可离线做组件与已知漏洞库比对，并记录
   漏洞库更新时间、版本匹配依据与误报可能；经明确授权的应用检查单独立项、
   复核和验收。不能承诺一次 URL 输入就找出全部最新漏洞。任何新采集器须有
   同域、只读、时间/字节/页面/并发预算，重新校验重定向与解析地址；禁止把
   任意 URL 变成无限制批量任务。`httpx` 已依赖；只有确实需要页面调度时
   再接 Scrapy，不复制整套源码或引入另一套数据库。见
   `docs/PASSIVE_SITE_ASSESSMENT_UPSTREAM.md` 的许可证与选型记录。
5. **上线验收**：在受控真实域名上测认领、失效验证、首页响应、报告恢复、
   跨 Owner 访问、速率限制、旧新域名 HTTPS、重启恢复和回滚。线上 Provider、
   VPS 和真实站点未通过之前，保留 NOT_VERIFIED 状态。

## 智能路由约束

路由输入是 Intent/Mission 规格、已验证站点范围、预算、所需能力、工具权限和
验收方法。规划、采集、报告撰写、独立核验分别留事件；Agent/模型不能自行扩大
目标域或取得 Owner 权限。优先按实测成功率、延迟、成本、配额及并发槽位选模型：
复杂规划与复核使用高推理配置，常规分类/摘要使用快速低成本配置，失败走现有
`router.py`/`quota.py`/`gateway.py` 回退，全部不可用如实失败。不能用一个模型的
自评替代来源证据或验收；不要为了漂亮进度制造假百分比。

当前已实现：单站点根 URL、控制权验证、每次运行重新验证、固定公网 IP 连接、
无跳转、上限响应读取、Owner 隔离、跨进程每 Owner 每分钟一次限额、持久报告。
当前未实现：深层页面采集、PHP 源码漏洞审计、Proof 绑定、公开预览、下载包、
真实 VPS 双域名发布与真实受控站点验收。
