# 跨设备同步实况（2026-11-04）

## 已接通：同一服务的桌面与手机

桌面控制台与手机页连接同一个 FACAI API 时，任务、执行事件和产物来自同一持久数据库，并受同一 Owner 会话权限约束。任务事件由 `/api/v1/missions/{id}/stream` 持久 SSE 送达；手机监控收到事件后重新读取任务快照，4 秒轮询用于断流兜底。跨设备访问仍需要已部署、可从手机到达的 HTTPS 服务。浏览器专项测试关闭轮询并验证了 SSE 驱动刷新；未把本机浏览器测试写成真实手机/VPS验收。

## 未接通：本地 Electron 数据库与 VPS 双向同步

`FACAI_DESKTOP_MODE=local` 启动本机 SQLite，和 VPS 上的 SQLite 是两个独立数据源。目前没有增量复制、冲突裁决、断线队列或跨节点 Owner 身份合并。不要将 GitHub 的 `SYNC-001` 代码检查点误写成业务数据同步，也不要在界面标记本地云端同步成功。

若需多设备立刻看到同一任务，应让桌面与手机均使用同一个远程 FACAI 服务。长期离线双向同步应单独设计记录版本、Owner 身份、事件顺序、冲突与删除语义，再实施迁移和验收。
